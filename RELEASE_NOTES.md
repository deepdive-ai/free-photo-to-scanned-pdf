# 0.3.0

- Local desktop launcher with photo selection, page reordering and PDF export.
- Color default, with grayscale and black-and-white modes.
- Automatic perspective correction and robust top/bottom crop fallback.
- Manual corner correction via CLI.
- Five automated scanner tests.
- Portable agent-plugin manifest and reusable scanning workflow.

Known limitations: no OCR, HEIC decoder bundled, or native executable packaging. Automatic crops require review. Desktop UI is syntax-checked but not interactively tested on all operating systems; ChatGPT import/execution is unverified.
